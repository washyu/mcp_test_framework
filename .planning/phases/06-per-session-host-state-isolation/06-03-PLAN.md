1. sha256-snapshot the 3 named real files (or skip if `~/.homelab_mcp/` absent — D-11).

       def _sha256_of(p: Path) -> str | None:
           """Return hex sha256 of p's bytes, or None if p doesn't exist.

           D-09: sha256 over file contents — NOT stat().st_mtime. mtime-only would
