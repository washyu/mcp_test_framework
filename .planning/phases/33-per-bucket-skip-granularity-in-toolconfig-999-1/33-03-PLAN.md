<objective>
Extend the v1.1.1 collection-time skip pattern in `_plugin.py` to also drop per-bucket tests at parametrize time. Skipped buckets must be invisible to `pytest --collect-only` for the affected tool — NOT rendered as runtime SKIPPED rows.

Purpose: BUCKET-02 / SC#1. Same hotfix invariant as v1.1.1 / 260508-p0b (project memory MEM:project_v1_1_skip_bug): excluded tests are excluded at parametrize time, never via runtime `pytest.skip()`. The whole-tool filter already lives in `pytest_collection`; the per-bucket filter is a sibling step in `pytest_generate_tests` where the parametrize list per test function is built.

Output:
- Per-bucket filter applied inside `pytest_generate_tests` (filters the `names` list per test function via `TEST_FUNCTION_BUCKETS`).
- Self-tests pinning collect-only absence of skipped-bucket tests AND presence of non-skipped buckets.
</objective>

       # Per-bucket filter: drop tools whose skip_buckets contains the
       # bucket owning this test function. Symmetric with the v1.1.1
       # whole-tool collection-time filter -- excluded (tool, test) cells
       # are absent from `pytest --collect-only` rather than rendered as

       if cfg is not None:
           func_name = metafunc.function.__name__
           owning_bucket: BucketName | None = None
           for bucket_name, fn_set in TEST_FUNCTION_BUCKETS.items():
               if func_name in fn_set:
                   owning_bucket = bucket_name  # type: ignore[assignment]
                   break
           if owning_bucket is not None:
               filtered: list[str] = []
               for tool_name in names:
                   tcfg = cfg.tools.get(tool_name)
                   if tcfg is None or owning_bucket not in tcfg.skip_buckets:
