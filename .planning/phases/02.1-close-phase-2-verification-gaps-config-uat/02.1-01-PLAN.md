<objective>
Fix the Windows-fatal `io.UnsupportedOperation: fileno` crash that breaks Phase 2 SC#2 by removing the incompatible `errlog=_LoggerWriter(_log)` argument from the `stdio_client(...)` call inside `McpTestClient.__aenter__`. This is a localized lifecycle fix per Phase 02.1 CONTEXT.md D-07 (absorb territory) and matches RESEARCH.md §Critical Finding 2 Option B (smallest diff).

Purpose: Without this fix, the `live_homelab` smoke test for SC#2 (run by Plan 02.1-03) fails immediately on Windows with `subprocess.py:1420 errwrite = msvcrt.get_osfhandle(stderr.fileno())` -- Windows `CreateProcess` requires a real OS file descriptor and `io.TextIOBase` has none. The fix preserves the public `McpTestClient(command, args, timeout_seconds)` signature (Phase 2 D-08 lock), keeps `shutil.which()` pre-flight intact (Phase 02.1 D-03), and leaves stderr surfaced via the SDK default (parent process inheritance -- pytest captures it cleanly with `-rA` / `--log-cli-level`).

Output: Patched `src/mcp_test_framework/mcp_client.py`; updated `tests/unit/test_mcp_client.py` reflecting the chosen retention policy for `_LoggerWriter` (see Task 2).
</objective>
