## Canonical invocation

| Option | Description | Selected |
|--------|-------------|----------|
| `uvx homelab-mcp` as default | Zero-install on fresh checkout; matches user's working `.env`/`config.yaml`; `uv` is already a hard dep so `uvx` is always present | ✓ |
| Direct binary (`MCP_SERVER_COMMAND=homelab-mcp`) as default | Current `.env.example` shape; requires `uv tool install homelab-mcp` first; no uvx wrapper overhead | |
| Both equally documented (no default) | Force the user to choose; README explains the trade-off | |

**Choice:** uvx default. **Rationale:** auto-mode picks the recommended option — minimum friction for fresh-checkout. Direct binary still works, just isn't the example value.
