<objective>
Close GAP 1 (blocker) from 14-HUMAN-UAT.md: the default `mcp-test-framework run` path crashes on Windows PowerShell's default cp1252 console with `UnicodeEncodeError` (write-side, glyph `✗`) and `UnicodeDecodeError` (read-side, byte `0x97` = cp1252 em-dash). The renderer correctly emits U+2717 / U+2014 / U+2013 glyphs (locked at Phase 09 SC-3), but `cli.run` never reconfigures stdout, and `_runner.run_pytest_subprocess` reads child output as utf-8 without setting `PYTHONIOENCODING=utf-8` in the child env or `errors='replace'` on the parent decoder.

Purpose: Phase 14's stated truth ("default run renders the full domain UI on every Python-supported platform") is currently false on Windows. The fix is two-sided encoding hygiene with a graceful-degradation fallback for streams that cannot reconfigure.

Output: cli.py reconfigures sys.stdout to utf-8 with errors='replace' (guarded), _runner.run_pytest_subprocess passes PYTHONIOENCODING=utf-8 to the child env and uses errors='replace' on the parent's decode, and tests/test_runner_encoding.py contains two regression tests that fail without the fix.
