Check 1: text format sorted alphabetically + 2-space indent
================================================================================
Command:
  uv run python -c "
  from mcp.types import Tool
  from mcp_test_framework.cli import _format_tools_text
  tools = [
      Tool(name='zebra', description='Z desc here', inputSchema={'type': 'object'}),
      Tool(name='apple', description='A desc here', inputSchema={'type': 'object'}),
      Tool(name='mango', description='M desc here', inputSchema={'type': 'object'}),
  ]
  out = _format_tools_text(tools)
  print(out)
  assert out.index('apple') < out.index('mango') < out.index('zebra')
  assert '  A desc here' in out
  print('OK: text format sorted + indented')
  "

    A desc here

  mango
    M desc here

  zebra
    Z desc here
  OK: text format sorted + indented

Result: PASS
  - Tool order is alphabetical (apple < mango < zebra)
  - Descriptions are indented with two spaces ('  A desc here')
  - Names are unindented on their own lines
  - Blank line separates tool blocks ("\n\n".join)

Check 2: JSON format sorted + full record + trailing newline
================================================================================
Command:
  uv run python -c "
  import json
  from mcp.types import Tool
  from mcp_test_framework.cli import _format_tools_json
  tools = [
      Tool(name='zebra', description='Z', inputSchema={'type': 'object', 'properties': {}}),
      Tool(name='apple', description='A', inputSchema={'type': 'object', 'properties': {'x': {'type': 'string'}}}),
  ]
  out = _format_tools_json(tools)
  data = json.loads(out)
  assert isinstance(data, list) and len(data) == 2
  assert data[0]['name'] == 'apple' and data[1]['name'] == 'zebra'
  for t in data:
      assert set(t.keys()) >= {'name', 'description', 'inputSchema', 'outputSchema'}
  assert out.endswith('\n')
  print('OK: JSON format sorted + full record + trailing newline')
  "

Output:
  OK: JSON format sorted + full record + trailing newline

Result: PASS
  - JSON is a 2-element array
  - Sort by name: apple before zebra
  - Each record has all four keys: name, description, inputSchema, outputSchema
  - Trailing newline present (composes with shell pipelines)
