<objective>
Switch the SDET `tool().call()` serializer from `params.model_dump(mode="json")` to `params.model_dump(mode="json", exclude_unset=True)` and lock the user-visible contract with three new payload-asserting unit tests + a one-line update to the existing kwargs-spy test. SEED-022 is preserved by construction — `exclude_unset` filters on **user intent** (did the SDET set this attribute on the model?) rather than on **value** (`is None`), so explicit-null-testing still flows `null` on the wire.

Purpose: eliminate the framework's contribution to `Input validation error: None is not of type 'string'` failures against MCP servers whose `inputSchema` declares optionals as `type: "string"` without `"null"`. The fix is structurally narrow (one kwarg) and SEED-022-compatible.

Output: serializer change + 3 new tests + 1 renamed test + 1 new SERIALIZER-01 requirement row + traceability row.
</objective>
