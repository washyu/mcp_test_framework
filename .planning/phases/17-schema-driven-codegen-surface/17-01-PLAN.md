CODEGEN-04 fallback chain for ToolResponse.data (locked by D-07 + RESEARCH §Code Examples 1):
  1. raw.structuredContent if present → return as-is
  2. else: try json.loads(first TextContent.text) — if parses to a dict, return it
  3. else: if any text was concatenated, return {"text": <concat>}
  4. else: None

ToolResponse class shape (verbatim from RESEARCH §Code Examples 1, lines 706-769):

```python
class ToolResponse(BaseModel):
    model_config = ConfigDict(arbitrary_types_allowed=True)
    raw: CallToolResult

    @computed_field
    @property
    def is_error(self) -> bool:
        return self.raw.isError

    @computed_field
    @property
    def text(self) -> str:
        return "".join(
            b.text for b in self.raw.content
            if isinstance(b, TextContent)
        )

    @computed_field
    @property
    def data(self) -> dict[str, Any] | None:
        if self.raw.structuredContent is not None:
            return self.raw.structuredContent
        for block in self.raw.content:
            if isinstance(block, TextContent):
                try:
                    parsed = json.loads(block.text)
                except (json.JSONDecodeError, ValueError):
                    parsed = None
                if isinstance(parsed, dict):
                    return parsed
                break
        concat = self.text
        if concat:
            return {"text": concat}
        return None
```

```python
"""ToolResponse base -- uniform .raw / .data / .text / .is_error per CODEGEN-04.

Per Phase 17 CONTEXT.md decisions:
  - D-07: Pydantic v2 BaseModel with @computed_field properties; lazy
    evaluation via @property (NOT eager-parsed at construction). Subclasses
    inherit accessors and may add typed fields (typed Response classes when
    outputSchema is declared) or remain stubs (D-06: stub when undeclared).
  - D-04: pyright is the static-type-check verifier; this module must be
    pyright-strict-clean.

CODEGEN-04 .data fallback chain (locked):
  1. raw.structuredContent if present
  2. else: JSON-parse first TextContent (must parse to a dict)
  3. else: {"text": <concat of all TextContent>} if any text exists
  4. else: None

Phase 17 boundary: this module ships the BASE only. Generated <Tool>Response
classes (created by `gen-sdet-classes`, Plan 17-04) inherit from ToolResponse
and either pass-stub or add typed fields. The .call() runtime that constructs
ToolResponse instances is wired in Phase 18 (mcp_session fixture).

Pitfall 7 (17-RESEARCH.md): CallToolResult.content is heterogeneous
(TextContent | ImageContent | AudioContent | ResourceLink | EmbeddedResource).
.text MUST filter on isinstance(block, TextContent) -- never .getattr('text')
naively.
"""
from __future__ import annotations

import json
from typing import Any

from mcp.types import CallToolResult, TextContent
from pydantic import BaseModel, ConfigDict, computed_field


class ToolResponse(BaseModel):
    """Uniform response surface for every MCP tool, regardless of outputSchema.

    Subclasses generated by ``gen-sdet-classes`` either add typed fields (when
    outputSchema is declared) or are stubs (``class FooResponse(ToolResponse):
    pass`` per D-06).
    """

    # arbitrary_types_allowed: CallToolResult is itself a Pydantic model from
    # `mcp.types` but Pydantic v2 strict mode requires this opt-in for any
    # external model used as a field type.
    model_config = ConfigDict(arbitrary_types_allowed=True)

    raw: CallToolResult

    @computed_field
    @property
    def is_error(self) -> bool:
        """Mirror of raw.isError (CODEGEN-04)."""
        return self.raw.isError

    @computed_field
    @property
    def text(self) -> str:
        """Concatenated TextContent.text across all content blocks.

        Non-TextContent blocks (Image/Audio/ResourceLink/EmbeddedResource) are
        silently skipped -- see Pitfall 7 in 17-RESEARCH.md. Naive
        ``b.text for b in raw.content`` would AttributeError on ImageContent.
        """
        return "".join(
            b.text for b in self.raw.content
            if isinstance(b, TextContent)
        )

    @computed_field
    @property
    def data(self) -> dict[str, Any] | None:
        """Best-effort dict view per CODEGEN-04 fallback chain.

        Order:
          1. raw.structuredContent if present (return as-is, even if empty dict)
          2. JSON-parse of first TextContent.text -- only counted if it parses
             to a dict (lists / scalars / null fall through)
          3. {"text": <concatenated text>} if any text content exists
          4. None

        Note: does NOT check is_error. Phase 18's tool().call() raises
        ToolCallError on isError=True; .data here returns whatever payload
        the server sent (Pitfall 8 in 17-RESEARCH.md).
        """
        if self.raw.structuredContent is not None:
            return self.raw.structuredContent
        for block in self.raw.content:
            if isinstance(block, TextContent):
                try:
                    parsed = json.loads(block.text)
                except (json.JSONDecodeError, ValueError):
                    parsed = None
                if isinstance(parsed, dict):
                    return parsed
                break  # only try the FIRST TextContent (CODEGEN-04 spec)
        concat = self.text
        if concat:
            return {"text": concat}
        return None
```

```python
"""Unit tests for mcp_test_framework.sdet.response.ToolResponse (CODEGEN-04, D-07).

Pins the .data fallback chain (structuredContent -> JSON-parse first TextContent
-> {"text": <concat>} fallback -> None), .text concatenation across mixed
content blocks (Pitfall 7 in 17-RESEARCH.md: must skip non-TextContent), and
.is_error mirror semantics.

Pure-sync (no asyncio) -- ToolResponse is a pure-data Pydantic model.
"""
from __future__ import annotations

from mcp.types import CallToolResult, TextContent

from mcp_test_framework.sdet import ToolResponse


def _result(
    *,
    content: list | None = None,
    structured: dict | None = None,
    is_error: bool = False,
) -> CallToolResult:
    return CallToolResult(
        content=content or [],
        structuredContent=structured,
        isError=is_error,
    )


def test_is_error_mirrors_raw() -> None:
    assert ToolResponse(raw=_result(is_error=False)).is_error is False
    assert ToolResponse(raw=_result(is_error=True)).is_error is True


def test_data_prefers_structured_content() -> None:
    """Step 1 of fallback chain: structuredContent wins even if text is also present."""
    raw = _result(
        content=[TextContent(type="text", text='{"ignored": true}')],
        structured={"foo": 1},
    )
    assert ToolResponse(raw=raw).data == {"foo": 1}


def test_data_parses_first_text_content_when_no_structured() -> None:
    """Step 2: JSON-parse first TextContent if structuredContent is absent."""
    raw = _result(content=[TextContent(type="text", text='{"foo": 1}')])
    assert ToolResponse(raw=raw).data == {"foo": 1}


def test_data_falls_back_to_text_dict_when_json_parse_fails() -> None:
    """Step 3: malformed JSON -> {"text": <concat>}."""
    raw = _result(content=[TextContent(type="text", text="not json at all")])
    assert ToolResponse(raw=raw).data == {"text": "not json at all"}


def test_data_falls_back_when_first_text_parses_to_non_dict() -> None:
    """Step 3: a JSON list / scalar at first TextContent does not count
    as structured -- falls through to {"text": ...}.
    CODEGEN-04 specifies dict-or-fallback explicitly."""
    raw = _result(content=[TextContent(type="text", text="[1, 2, 3]")])
    assert ToolResponse(raw=raw).data == {"text": "[1, 2, 3]"}


def test_data_returns_none_when_no_content_and_no_structured() -> None:
    """Step 4: empty content and no structuredContent -> None."""
    assert ToolResponse(raw=_result()).data is None


def test_text_concatenates_text_blocks() -> None:
    raw = _result(content=[
        TextContent(type="text", text="hello "),
        TextContent(type="text", text="world"),
    ])
    assert ToolResponse(raw=raw).text == "hello world"


def test_text_skips_non_text_blocks_pitfall_7() -> None:
    """Pitfall 7 (17-RESEARCH.md): naive iteration would AttributeError on
    ImageContent / AudioContent / ResourceLink / EmbeddedResource. .text
    MUST filter via isinstance(block, TextContent)."""
    from mcp.types import ImageContent
    raw = _result(content=[
        TextContent(type="text", text="hi"),
        ImageContent(type="image", data="aGVsbG8=", mimeType="image/png"),
        TextContent(type="text", text=" there"),
    ])
    # No AttributeError; image block is skipped, text blocks concatenate.
    assert ToolResponse(raw=raw).text == "hi there"


def test_data_does_not_check_is_error_pitfall_8() -> None:
    """Pitfall 8: .data returns whatever payload the server sent, even when
    is_error=True. Phase 18's ToolCallError surfaces the error; Phase 17 keeps
    .data spec-literal (no early return on error)."""
    raw = _result(
        content=[TextContent(type="text", text='{"error": "bad input"}')],
        is_error=True,
    )
    response = ToolResponse(raw=raw)
    assert response.is_error is True
    assert response.data == {"error": "bad input"}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP server → ToolResponse | `raw` field accepts an `mcp.types.CallToolResult` produced by an external (black-box) MCP server. The server is untrusted in the codegen-time sense (we generate code from its declared schemas) and the runtime sense (it produces the `CallToolResult` we wrap). |
| TextContent.text → json.loads | Server-controlled string is passed to `json.loads`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17.01-01 | Tampering | `ToolResponse.data` JSON-parse of first TextContent | mitigate | Wrap `json.loads` in `try/except (json.JSONDecodeError, ValueError)` → falls back to `{"text": <concat>}`; never raises. Pinned by `test_data_falls_back_to_text_dict_when_json_parse_fails`. |
| T-17.01-02 | Denial of Service | `json.loads` against arbitrarily large server-controlled text | accept | `json.loads` is the stdlib parser with no length limit; an MCP server returning a 100MB JSON blob would consume memory. Acceptable for v1.3: the framework itself bounds via `asyncio.timeout(timeout_seconds)` at the `call_tool` layer (not added by this plan -- already present in `mcp_client.py:209`). Codegen-time concern is out of scope (Plan 17-02). |
| T-17.01-03 | Information Disclosure | `.data` does not branch on `is_error`, so error payloads surface via `.data["..."]` | accept | This is the locked CODEGEN-04 spec (Pitfall 8). Phase 18's `ToolCallError` is the typed-error path. Documented in the `data` docstring + pinned by `test_data_does_not_check_is_error_pitfall_8`. |
| T-17.01-04 | Tampering | Non-TextContent blocks (ImageContent etc.) crashing `.text` accumulator | mitigate | `isinstance(block, TextContent)` filter; pinned by `test_text_skips_non_text_blocks_pitfall_7`. |
| T-17.01-05 | Spoofing | `arbitrary_types_allowed=True` in ConfigDict could let a malicious caller pass a non-`CallToolResult` object as `raw` | accept | `arbitrary_types_allowed` is required because `CallToolResult` is an "external" Pydantic model (Pydantic v2 strict mode quirk). Pydantic still validates the field type at construction -- a non-`CallToolResult` raises `ValidationError`. The opt-in is for the model's TYPE, not its content. |
