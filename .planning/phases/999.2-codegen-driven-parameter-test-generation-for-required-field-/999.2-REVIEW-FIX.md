### WR-02: `_validate_examples_shape` bracket-index error bypassed for non-list iterables

**Files modified:** `src/mcp_test_framework/models.py`
**Commit:** 8b55d22
**Applied fix:** Added a `try: v = list(v)` coercion block before the `isinstance(v, list)` check. When the input is not a list and not a dict, the validator now attempts to convert it to a list so the for-loop and bracket-notation error message fire uniformly for tuples, generators, and other sequences. Dict inputs still fall through to Pydantic's type-rejection. Non-iterable inputs fall through via the `except TypeError` branch. Valid tuple-of-dicts now coerces to `list` and is accepted. Verified with Python-API reproduction case: `ToolConfig(examples=({'vmid': 9001}, 42))` now raises `examples[1] must be a mapping...` instead of the old dot-notation Pydantic error.
