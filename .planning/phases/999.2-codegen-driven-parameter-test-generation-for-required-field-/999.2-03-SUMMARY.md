## Decisions Made

- **String annotation for `tools_config` kwarg:** The plan specifies `"dict[str, object] | None"` (not `"dict[str, ToolConfig] | None"`) to avoid importing `models.ToolConfig` into the pure-data `_codegen.py` module. Duck-typed access via `getattr(tool_cfg, "examples", None)` is the safe bridge. Consistent with the module's docstring ("Pure-data: reads dicts and emits strings").
- **TDD Task 3 colocated with Task 1:** Task 3's required tests were written as the RED phase of Task 1 — the TDD cycle naturally produced the required test coverage. No separate commit was needed.
