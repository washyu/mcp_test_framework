# Phase 25 Plan 02: Public-API Rename (sdet → test_code) — CLI Command + Flag Rename Summary

Renamed the operator-facing Typer command `gen-sdet-classes` to `gen-test-classes` and the `run` command's `--sdet` flag to `--test-code`. Both legacy names remain callable as `hidden=True` shims that each fire one stdlib `DeprecationWarning` per process naming the v1.4→v1.5 removal milestone. The new names are the only ones documented in `mcp-test-framework --help` and `mcp-test-framework run --help`.

## Objective Met

RENAME-02 acceptance text holds:
- `mcp-test-framework gen-test-classes --help` resolves and shows the usage block.
- `mcp-test-framework gen-sdet-classes` still resolves; emits one `DeprecationWarning` per process via Python's default filter (verified with `warnings.showwarning` hook).
- `gen-sdet-classes` is `hidden=True` and does not appear in `mcp-test-framework --help`; `gen-test-classes` does (one entry).

RENAME-03 acceptance text holds:
- `mcp-test-framework run --help` shows `--test-code`; does NOT show `--sdet`.
- `mcp-test-framework run --sdet` still works (operator gets the same scenario-scope behavior); emits one `DeprecationWarning` per process (verified by `CliRunner().invoke(app, ['run', '--sdet'])` showwarning capture).
- The visible help text describes `tests/test_code/` as the documented scope (plan 04 wires the actual dual-discovery; this plan locks the operator-facing vocabulary).
