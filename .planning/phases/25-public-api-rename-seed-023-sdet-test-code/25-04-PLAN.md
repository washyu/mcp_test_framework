    At the TOP of `tests/test_code/conftest.py` (after the module docstring + existing imports), add:

    ```python
    import warnings
    from pathlib import Path

    _LEGACY_SDET_WARNED = False  # noqa: sdet-rename-shim


    def pytest_collection_modifyitems(config, items):  # noqa: sdet-rename-shim
        """Fire one DeprecationWarning per session if any test was collected from tests/sdet/.

        Removed in v1.5 along with the dual-discovery fallback.
        """
        global _LEGACY_SDET_WARNED  # noqa: sdet-rename-shim
        if _LEGACY_SDET_WARNED:  # noqa: sdet-rename-shim
            return
        legacy_marker = f"tests{Path('/').as_posix()}sdet{Path('/').as_posix()}"  # 'tests/sdet/' cross-platform  # noqa: sdet-rename-shim
        for item in items:  # noqa: sdet-rename-shim
            if legacy_marker in item.nodeid.replace("\\", "/"):  # noqa: sdet-rename-shim
                warnings.warn(  # noqa: sdet-rename-shim
                    "tests/sdet/ is deprecated since v1.4 and will be removed in v1.5 — "
                    "move your test files to tests/test_code/ instead.",
                    DeprecationWarning,
                    stacklevel=2,
                )
                _LEGACY_SDET_WARNED = True  # noqa: sdet-rename-shim
                break
    ```

    Implementation notes:
    - The module-level `_LEGACY_SDET_WARNED` flag is the "once per session" gate. Without it, pytest's collection hook could fire per-item if multiple items collect from the legacy path.
    - The cross-platform marker `tests/sdet/` uses forward slashes; we normalize `item.nodeid` by replacing `\\` with `/` for Windows safety.
    - Every line referencing the legacy path or the shim flag carries `# noqa: sdet-rename-shim`.
    - If a `pytest_collection_modifyitems` hook ALREADY exists in `tests/test_code/conftest.py` (verify via read_first), extend that existing hook with this block rather than declaring a second one — pytest only calls one per conftest. Extend at the END of the existing hook so prior behavior is preserved.

    Do NOT add this hook to `tests/conftest.py` (the parent root conftest) — its scope is the whole tree; we want the warning to fire only when the dogfood scope is active.
