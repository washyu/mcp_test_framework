## Deviations from Plan

### Deviation 1 (Rule 1 — bug-fix): `anyio.fail_after` API mismatch in plan's verbatim Variant B
- **Found during:** Task 2 implementation
- **Issue:** The plan's verbatim Variant B used `async with anyio.fail_after(seconds):` but in anyio 4.x `fail_after` is a synchronous context manager (returns a `CancelScope`). `async with` raises `TypeError` at runtime.
- **Fix:** Substituted `with anyio.fail_after(seconds):` (verified empirically against `.venv/Lib/site-packages/anyio/_core/_tasks.py`).
- **Files modified:** `src/mcp_test_framework/fixtures.py` (one-character change inside the owner task body).
- **Verification:** ruff clean; importable; included in commit `686a265` (and unchanged in subsequent `82fa53b`).
- **Committed in:** `686a265` (initially), preserved in `82fa53b`.

### Deviation 2 (Rule 1 — bug-fix): Variant B did not fix the bug; superseded by debug-derived Option (a)
- **Found during:** Task 3 (`checkpoint:human-verify` live verification).
- **Issue:** Variant B as committed in `686a265` failed live verification. The cancel-scope error reappeared at `src/mcp_test_framework/fixtures.py:207` (`async with anyio.create_task_group() as tg:`) — the same Pitfall 1 one frame outward. RESEARCH §A2-residual had flagged this as a residual MEDIUM-confidence assumption pending a 5-minute spike that was never run.
- **Root cause:** pytest-asyncio's `plugin.py:308-330` schedules `setup()` and `async_finalizer()` as two distinct top-level asyncio.Tasks via separate `runner.run(...)` calls. anyio's `CancelScope.__exit__` rejects exit-on-different-task-than-enter; the outer task_group's `__aexit__` therefore raised on session teardown.
- **Fix:** Replaced the fixture body with a pure-asyncio driver (`asyncio.create_task` + `asyncio.Future` + `asyncio.Event`). All anyio cancel scopes (`stdio_client`, `ClientSession`, `anyio.fail_after`) live exclusively inside the owner task, so their enter/exit pairs are always on the same task. The fixture body holds zero anyio cancel scopes across the yield.
- **Files modified:** `src/mcp_test_framework/fixtures.py` (fixture body + imports: added `asyncio`, `contextlib`; removed `anyio.abc` since `TaskStatus` is no longer used; kept `anyio` for `fail_after` inside the owner).
- **Verification:** Live `uv run pytest tests/test_homelab_list_registered_servers.py -v` against `list_keyring_credentials` returned `10 passed in 14.95s`, `EXIT_CODE=0`, no cancel-scope substring; `Get-Process homelab-mcp` empty after run.
- **Committed in:** `82fa53b`.
- **Audit trail:** Full root-cause analysis, hypothesis confirmation, alternatives evaluation, and elimination chain preserved at `.planning/debug/fixture-teardown-cancel-scope.md`.
