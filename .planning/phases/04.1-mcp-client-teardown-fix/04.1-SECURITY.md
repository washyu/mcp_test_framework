# Phase 04.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Threat Register

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-04.1-01 | Tampering | Outer subprocess test argv | mitigate | argv passed as Python list, not shell string. No `shell=True`. No env-var interpolation into argv. Verified at `tests/smoke/test_mcp_client_teardown_regression.py:90` (`subprocess.run([sys.executable, "-m", "pytest", ...], ...)`). | closed |
| T-04.1-02 | Information disclosure | Outer test child output capture | accept | Child stdout+stderr captured into failure diagnostic; no secrets flow through stdio_client (`OLLAMA_BASE_URL` and `MCPTF_CONFIG_FILE` are paths/URLs, not credentials). Diagnostic truncated to last 2000 chars to bound exposure (`output[-2000:]` at lines 111 and 121). Accepted risk logged below. | closed |
| T-04.1-03 | Denial of service | Outer subprocess test (hang or recursion) | mitigate | (a) `subprocess.run(..., timeout=120)` bounds wall-clock at 2 min — child pytest force-killed if it hangs (line 103). (b) Exact test selector `tests/smoke/test_mcp_client_teardown_regression.py::test_mcp_client_teardown_completes_cleanly` ensures the child runs ONE inner test, not the outer (line 92) — prevents infinite recursion of `outer → child outer → grandchild outer → …`. | closed |
| T-04.1-04 | Denial of service | Owner task in `mcp_client` fixture (hung `stdio_client.__aenter__`) | mitigate | Owner-task setup bounded by `anyio.fail_after(config.mcp_server.timeout_seconds)` around `session.initialize()` (`src/mcp_test_framework/fixtures.py:223`). Fixture body bounds the ready-await with `asyncio.wait_for(asyncio.shield(ready), timeout=config.mcp_server.timeout_seconds + 5)` (line 241) — owner errors propagate via `ready.set_exception(...)`. Teardown bounded by `asyncio.wait_for(owner, timeout=10)` with `owner.cancel()` fallback (line 255). The MCP SDK's `stdio_client` already wraps `await process.wait()` in `anyio.fail_after(PROCESS_TERMINATION_TIMEOUT)` for shutdown. NOTE: Disposition shape evolved during execution — the plan's `tg.start()` was replaced with an `asyncio.Future`-based driver (debug-derived fix `82fa53b`); the timeout-bounding intent is preserved. | closed |
| T-04.1-05 | Elevation of privilege | `MCPTF_CONFIG_FILE` env var inheritance into child pytest | accept | Child inherits parent env via `{**os.environ, "MCPTF_CONFIG_FILE": str(config_file)}` (line 89). `MCPTF_CONFIG_FILE` points to a path the parent user already has read access to — no privilege escalation possible. Accepted risk logged below. | closed |

Disposition remains `mitigate / closed`.
