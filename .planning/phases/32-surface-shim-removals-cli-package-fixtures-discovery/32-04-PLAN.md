<objective>
Strip the `tests/sdet/` dual-discovery surface from the framework runtime so only `tests/test_code/` is collected. Replace the existing DeprecationWarning-emitting dual-discovery with a single warn-on-presence detector at `pytest_collection` that fires only when an operator has a stale `tests/sdet/` directory with live `test_*.py` files. Scrub the 26 `# noqa: sdet-rename-shim` markers grandfathering dual-discovery code across `_runner.py` (~21), `fixtures.py` (4), and `_reporter.py` (1); delete the single misapplied marker on `_black_box_guard.py:10` while preserving the SEED-022 prose. Refactor the nested `_mcptf_formatwarning` helper to module-level so the new warn site reuses Plan 31-02's `[mcp-contracts]`-prefixed renderer. Rename the `sdet=` kwarg through `_runner.py` + the two `cli.py` call sites at L837 + L940. Delete the on-disk `tests/sdet/` directory (dead `_generated/` + `__pycache__/`). Ship the pytester regression test AND the ERROR-STYLE-registry pin in `test_error_style.py` that mirrors Plan 31-01's `test_error_style_sdet_rejection_message` shape.

Purpose: SHIM-06 closes the v1.4 deprecation window for the `tests/sdet/` discovery fallback. Per CONTEXT D-05 + 32-RESEARCH.md, the pattern is "warn, not hard-fail" so operators mid-migration with stale directories see a loud signal without losing the ability to run their `tests/test_code/` suite. The Phase 31 D-08 formatwarning override is the inherited rendering layer.

Output: Modified `_plugin.py` (new warn block + module-level formatwarning helper), gutted dual-discovery in `_runner.py` + `fixtures.py` + `_reporter.py`, renamed kwarg at the two cli.py call sites, deleted misapplied marker in `_black_box_guard.py`, new pytester regression test, new pinned-text registry entry in `test_error_style.py`, deleted on-disk `tests/sdet/` directory.
