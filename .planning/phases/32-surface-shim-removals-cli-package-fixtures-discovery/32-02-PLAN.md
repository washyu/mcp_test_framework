<objective>
Convert the existing `--sdet` Typer flag's deprecation-warning callback into a hard-rejecting callback that raises `typer.BadParameter` with an operator-tone three-part message naming `--test-code`. Keep the option registered as `hidden=True` so legacy operator argv (`mcp-contracts run --sdet`) still parses cleanly enough to surface the migration message. Delete the now-dead `sdet_legacy → test_code` coercion in `run()`.

Purpose: SHIM-02 closes the v1.4 deprecation window for the `--sdet` CLI flag. Hidden + hard-raise preserves the pointer-at-the-new-name guarantee that success criterion #2 requires (stock Typer `No such option: --sdet` would not name `--test-code`). The Typer skeleton at `cli.py:735-742` is already on the right shape (`hidden=True`, `is_eager=True`, `callback=_warn_sdet_flag`); this plan flips the callback body and updates the help text.
