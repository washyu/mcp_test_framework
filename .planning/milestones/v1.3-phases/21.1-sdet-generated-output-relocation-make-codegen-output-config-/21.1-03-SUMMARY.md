## Confirmation: HYBRID strategy

- **Mock-based half** (Tasks 1 & 2): both unit-test files now drive codegen into tmp_path via the framework's own `_codegen.generate(...)` call, then point `cfg.sdet.generated_root` at that tmp_path. The framework's load mechanism (Plan 02's `spec_from_file_location` in `session.py`) is exercised against the test-owned artifacts. No live MCP dependency.
- **Live-regen half** (Task 3): `test_proxmox_vm_lifecycle_readme_sample.py` reads `cfg.sdet.generated_root` at module-import time and loads the homelab_mcp package via the same spec-loader pattern the framework uses internally. The file does NOT regenerate the package itself — the operator must have run `mcp-test-framework gen-sdet-classes` for homelab-mcp before opting in via the `live_homelab` marker (mirrors the live-gate pattern already used at `test_gen_sdet_classes_cli.py::test_live_homelab_emit_smoke`).

Plan rationale (CONTEXT.md D-09, captured verbatim in PLAN.md `<objective>`): mock-only would break the README parity test's whole reason for existing (it MUST show real homelab-mcp output); live-only would force CI to depend on Proxmox + homelab-mcp, which the project already rejects. HYBRID mirrors the existing live-gate pattern at `test_gen_sdet_classes_cli.py:185-218`.

## Decisions Made

See `key-decisions` in the frontmatter. The most load-bearing decisions:
1. **`pytest.skip(allow_module_level=True)` in the README-sample loader** — collection runs module top-level code even when `pytestmark` deselects all tests. A `FileNotFoundError` at module level would become a collection ERROR (not "0 collected"). Wrapping the load in try/except + `pytest.skip(..., allow_module_level=True)` keeps collection clean in environments without a homelab_mcp/ tree under `cfg.sdet.generated_root`.
2. **`_REGISTRIES_snapshot` deep copy in `_run_fixture`** — Plan 18's snapshot only captured the key set + the homelab_mcp registry reference. Post-21.1, the registry is teardown-popped before the assert runs, so the deep copy is needed to verify yield-time registry contents (the "echo_message" tool is in the registry at yield, gone after teardown).
3. **D-10 preserved verbatim** — `test_codegen_integration_mock.py` is contractually unchanged. One docstring line (line 18: "Does NOT touch src/mcp_test_framework/sdet/generated/homelab_mcp/") references the framework namespace as an *exclusion*, not an import dependency. The reference becomes informationally stale after Plan 04 deletes that tree; rewording is Plan 04's scope (or a future cleanup), not 21.1-03's.
