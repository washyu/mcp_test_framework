## Default output location

| Option | Description | Selected |
|--------|-------------|----------|
| `./tests/sdet/_generated/<slug>/` | Colocated with `tests/sdet/` scenarios; underscore prefix marks 'tool-managed.' Recommended initially. | |
| `./generated/<slug>/` | Top-level project dir. Most discoverable; adds another root-level directory. | |
| `./.mcptf/generated/<slug>/` | Hidden cache dir under a `.mcptf/` namespace. Easy to gitignore but dotfile imports are awkward. | |
| No default — require `sdet.generated_root` in config.yaml | Fail-loud if unconfigured. Forces operator intent. | ✓ |

**User's choice:** No default — require `sdet.generated_root` in config.yaml
**Notes:** Aligns with v1.2's SAFE-03 fail-loud-on-missing-config posture. Framework never silently invents paths. Operator pays a one-time config-init cost; safer than guessing.

## Config + override mechanism

| Option | Description | Selected |
|--------|-------------|----------|
| `config.yaml` only | One source of truth. No CLI flag, no env var. Cleanest mental model. | ✓ |
| `config.yaml` + CLI `--out` | config.yaml default; `--out PATH` on `gen-sdet-classes` overrides for ad-hoc regens. NO env var. | |
| `config.yaml` + CLI `--out` + `MCPTF_GENERATED_ROOT` env | Full CLI > env > config precedence. More surface area; reintroduces env-overlay footgun. | |

**User's choice:** `config.yaml` only
**Notes:** Path is a property of the project's test layout, not a per-invocation knob. SDETs set it once at setup. Skipping the env var dodges the silent-override footgun documented in `project_dotenv_silently_beats_config` memory.

## Import strategy after relocation

| Option | Description | Selected |
|--------|-------------|----------|
| Filesystem path + `spec_from_file_location` | Framework loads `<root>/<slug>/__init__.py` directly. No `sys.path` mutation. SDET imports their own layout choice. | ✓ |
| Python module path + `importlib.import_module` | Config holds dotted module path. Framework imports by name. Same identifier for fixture and SDET test imports. Requires module to be importable. | |
| Filesystem path + `sys.path` insert | Framework prepends parent dir to `sys.path`; SDETs get free imports by simple name. Mutates a global. | |

**User's choice:** Filesystem path + `spec_from_file_location`
**Notes:** Cleanest separation between framework load mechanism and SDET test imports. Framework doesn't care about `sys.path`; SDET arranges their own package layout for their test files.
