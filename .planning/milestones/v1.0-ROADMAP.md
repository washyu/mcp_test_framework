# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-06
**Phases:** 01 → 05 (with inserted 02.1 and 04.1)
**Total Plans:** 22

## Overview

The v1.0 MVP delivers a `pytest`-runnable test suite that exercises one MCP tool end-to-end (schema → call → judge) against `homelab-mcp` over stdio. Build order was risk-first: a pure-data foundation (uv, pytest-asyncio config, black-box lint, config precedence, schema validator) locked down the bootstrap choices before any I/O landed; then the two integration risks (MCP stdio subprocess, Ollama HTTP judge) each got a dedicated phase with a smoke step before any fixture depended on them; then session-scoped fixtures wired everything into the 10 spec'd tests; finally the Typer CLI + README closed out the acceptance criteria. Two decimal phases were inserted mid-milestone to close discovered gaps (Phase 02.1 reconciled config docs and ran live `homelab-mcp` smoke; Phase 04.1 fixed an `anyio` cancel-scope teardown bug that gated exit code 0).
